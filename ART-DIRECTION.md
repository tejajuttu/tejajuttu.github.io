# Custom visual system

Three original conceptual illustrations were generated using the built-in image generation tool, with separate agents working from a shared palette and material direction. They are illustrations, not screenshots or representations of client systems.

- [Alpine observatory — exact prompt](public/art/alpine-observatory.prompt.md): slate, snow, copper route, illuminated waypoints, summit lens.
- [Multimodal lens — exact prompt](public/art/multimodal-lens.prompt.md): smoked glass, alpine media panels, waveform, focused copper beam.
- [Agent instrument — exact prompt](public/art/agent-instrument.prompt.md): graphite discs, controlled copper connections, sage glass lens, illuminated core.

Original 1536 × 1024 PNGs are preserved alongside WebP delivery versions in `public/art/`. WebP encoding preserves composition and dimensions; the three delivered files total approximately 440 KB. The main page uses WebP, lazy-loads project art, and only loads the Three.js terrain renderer when the visitor requests 3D.

The portfolio combines a compact project grid, a persistent navigation dock, explicit project actions, and optional games. The FDE scenario is a scripted fictional exercise with no external AI calls, scoring, or collection of user choices.
